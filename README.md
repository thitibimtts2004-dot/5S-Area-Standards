# 5ส Pro — แบบตรวจ 5ส

แอปตรวจ 5ส สำหรับมือถือ ไม่ต้องติดตั้งอะไร เปิดผ่านเบราว์เซอร์ได้ทันที

**เปิดใช้งาน:** https://thitibimtts2004-dot.github.io/5S-Area-Standards/

## ความสามารถ
- ตรวจ 5ส แยกตามพื้นที่ (Office / Store / โรงแบบอลูมิเนียม / กำหนดเอง) — 25 หัวข้อ × 4 คะแนน
- ถ่ายรูปแนบจุดบกพร่องได้จากกล้องมือถือโดยตรง
- เก็บประวัติการตรวจ + จัดอันดับ (Ranking) ในเครื่อง
- พิมพ์รายงานผลการตรวจเป็น PDF ขนาด A4 หน้าเดียว
